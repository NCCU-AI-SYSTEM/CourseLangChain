4 · 三層 Harness

L1 · input_sanitizer

regex 偵測 prompt injection、控制 token、長度上限(500)。不安全直接擋,不送進 LLM。

L2 · SafeAgentExecutor 改寫

包 LangGraph CompiledGraph(原本是包 LangChain AgentExecutor)。recursion_limit=2·max_steps+1、daemon thread 真逾時(120s)、例外轉友善訊息,永不 raise。

L3 · output_validator

驗證器登記制。schedule_tool 自註冊 schedule_no_conflict:逐「### 方案」檢查衝堂,fail-open 防誤殺。
